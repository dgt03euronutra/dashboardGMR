# Dashboard Consumos

Prototipo navegable de un dashboard para consumos de agua, gas, electricidad y placas solares. Utiliza datos de demostración en el navegador.

## Desarrollo local

```sh
npm ci
npm run dev
```

## Publicación

El workflow de GitHub Actions construye la aplicación y publica `dist` en GitHub Pages cada vez que se actualiza `main`. También se puede iniciar manualmente desde la pestaña **Actions**.
